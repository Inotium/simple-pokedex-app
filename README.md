# A Simple Pokédex App

A **A Simple Pokédex App** built with **Flutter** that lets users explore Pokémon from different generations. The app fetches detailed Pokémon data from the **PokéAPI**, including  images, stats, abilities, evolution chains, and more.

## Features
- Browse **Pokémon by generation**.
- View **images** of Pokémon.
- Detailed **Pokémon information** including:
  - **Types**
  - **Base stats** (with visual progress bars)
  - **Abilities**
  - **Evolution chain** (with images of evolutionary stages)
- **Responsive UI**
